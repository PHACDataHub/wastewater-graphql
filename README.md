# Wastewater API
Prerequisites
- Python 3.14 or higher
- uv installed on your system

# Installing uv
If you don't have uv installed, you can install it using pip:
```
pip install uv
```

# Install Dependencies
Use uv to install the project dependencies:
```
uv sync
```

# Running the app
## Basic Execution
```
uv run fastapi dev
```
